집이나 사무실의 **ipTIME AX3000Q** 공유기에 연결된 Windows 노트북을 외부(카페, 이동 중 등)에서 **Microsoft Windows App**(구 Microsoft Remote Desktop)으로 언제든 접속하려면 다음 4가지를 순서대로 설정해야 합니다.

1. **노트북(Windows):** 원격 데스크톱(RDP) 활성화 및 전원/MAC 설정 확인
2. **공유기 내부 IP 고정:** 노트북의 사설 IP가 재부팅·재연결 시 바뀌지 않도록 고정
3. **DDNS 설정:** 통신사 공인 IP가 바뀌어도 고정 도메인(`xxx.iptime.org`)으로 접속
4. **포트포워드 설정:** 외부 접속 요청을 고정된 노트북의 `3389` 포트로 전달

---

### 1. 노트북(Windows) 사전 설정

#### 1) 원격 데스크톱 활성화
- **조건:** Windows **Pro / Enterprise** 에디션이어야 기본 원격 데스크톱 호스트 기능을 사용할 수 있습니다. (Home 에디션은 미지원)
- `설정(Win + I)` → `시스템` → `원격 데스크톱`으로 이동하여 **원격 데스크톱**을 **켬**으로 변경합니다.

#### 2) 절전 모드 및 덮개 설정 확인
- 노트북이 절전 모드에 들어가면 외부에서 접속할 수 없습니다.
- `설정` → `시스템` → `전원 및 배터리`에서 **전원 연결 시 절전 모드 진입**을 `안 함`으로 설정해 둡니다.
- 노트북을 닫고 사용하려면 `제어판` → `하드웨어 및 소리` → `전원 옵션` → `덮개를 닫으면 수행되는 작업 선택`에서 **전원 사용 시: 아무것도 안 함**으로 설정합니다.

#### 3) Wi-Fi 사용 시 '임의 하드웨어 주소' 끄기
- 노트북을 Wi-Fi로 연결하는 경우 Windows의 **임의 하드웨어 주소(MAC 주소 랜덤화)**가 켜져 있으면 공유기가 노트북을 다른 기기로 인식해 고정 IP가 풀릴 수 있습니다.
- `설정` → `네트워크 및 인터넷` → `Wi-Fi` → 연결된 SSID 클릭 → **임의 하드웨어 주소**를 **끔**으로 설정합니다.

---

### 2. ipTIME AX3000Q 내부 IP 고정 (DHCP 수동 할당)

공유기 관리자 페이지에 접속한 뒤 노트북에 할당된 사설 IP를 고정합니다.

1. 브라우저에서 `http://192.168.0.1`에 접속해 로그인 후 **관리도구**로 들어갑니다.
2. 왼쪽 메뉴에서 **고급 설정 > 네트워크 관리 > 내부 네트워크 설정**으로 이동합니다.
3. 화면 하단의 **사용중인 IP 주소 정보**(또는 DHCP 서버 수동 할당 목록)에서 현재 노트북의 **IP 주소**와 **MAC 주소**를 찾습니다.
   - 헷갈린다면 노트북 CMD/PowerShell에서 `ipconfig /all`을 실행해 `IPv4 주소`와 `물리적 주소(MAC)`를 확인합니다.
4. 해당 기기를 선택하고 **수동 등록**(고정 할당)을 클릭한 뒤 **적용**을 누릅니다.

> 이제 노트북을 재부팅하거나 Wi-Fi를 껐다 켜도 공유기가 항상 같은 내부 IP(예: `192.168.0.10`)를 부여합니다.

---

### 3. DDNS 설정 (외부 주소 고정)

가정용 인터넷은 공인 IP가 주기적으로 변경될 수 있으므로, ipTIME에서 무료 제공하는 DDNS 주소를 등록해 두는 것이 안전합니다.

1. **고급 설정 > 특수기능 > DDNS 설정**으로 이동합니다.
2. 아래 항목을 입력하고 **DDNS 등록** 버튼을 누릅니다.
   - **호스트 이름:** 원하는 이름 입력 (예: `mylaptop.iptime.org`)
   - **사용자 ID:** 본인 이메일 주소 입력
3. 등록 후 상태가 **정상 등록**으로 표시되는지 확인합니다.

---

### 4. 포트포워드 설정

외부에서 `DDNS주소:포트`로 들어오는 연결을 노트북의 RDP 기본 포트(`3389`)로 연결해 줍니다.

1. **고급 설정 > NAT/라우터 관리 > 포트포워드 설정**으로 이동합니다.
2. **새 규칙 추가**에서 아래와 같이 입력하고 **적용**합니다.
   - **규칙 이름:** `Laptop-RDP` (식별용 이름)
   - **내부 IP 주소:** 2단계에서 고정한 노트북 IP (예: `192.168.0.10`)
   - **프로토콜:** `TCP` (필요 시 `TCP/UDP`)
   - **외부 포트:** **임의의 높은 포트 번호 권장** (예: `33890` ~ `33890`)
   - **내부 포트:** `3389` ~ `3389`

> **보안 팁: 외부 포트는 `3389` 그대로 열지 마세요**  
> 외부 포트를 기본값 `3389`로 열어두면 자동화된 봇의 무차별 대입 공격(Brute-force) 대상이 되기 쉽습니다. **외부 포트만 `33890` 같은 비표준 포트로 지정하고 내부 포트를 `3389`로 매핑**하면 노트북 설정을 건드리지 않고도 스캐닝 공격 노출을 크게 줄일 수 있습니다.

---

### 5. Microsoft Windows App으로 외부 접속하기

모바일(iOS/Android)이나 다른 PC/Mac의 **Windows App** (구 Microsoft Remote Desktop)을 실행해 연결을 추가합니다.

1. **Connections(또는 PC 추가)**를 선택합니다.
2. **PC name / Host name**에 `DDNS주소:외부포트` 형식으로 입력합니다.
   - 예: `mylaptop.iptime.org:33890`
3. **User account**에 노트북의 Windows 로그인 계정과 비밀번호를 입력하고 저장합니다.
4. 스마트폰의 Wi-Fi를 끄고 **모바일 데이터(LTE/5G)** 상태에서 접속이 정상적으로 이루어지는지 테스트합니다.

---

### 접속이 안 될 때 체크리스트

- **Windows 방화벽 확인:** `고급 보안이 포함된 Windows Defender 방화벽` → `인바운드 규칙`에서 **원격 데스크톱 - 사용자 모드(TCP-In)**가 활성화되어 있는지 확인합니다. (특히 현재 네트워크 프로필이 `공용`으로 되어 있다면 해당 프로필 허용 여부 확인)
- **이중 공유기(이중 NAT) 환경 확인:** 통신사 모뎀/공유기 아래에 ipTIME AX3000Q가 연결된 구조라면, 상위 통신사 공유기에서도 AX3000Q의 WAN IP로 포트포워드(또는 DMZ/브릿지 모드 설정)가 필요합니다. 공유기 `시스템 요약 정보`의 **외부 IP 주소**가 `192.168.x.x`나 `10.x.x.x` 같은 사설 IP 대역이면 이중 NAT 상태입니다.
- **Microsoft 계정 로그인 오류 시:** Windows에 PIN으로만 로그인하던 경우 원격 접속 시 비밀번호 인증이 실패할 수 있습니다. 노트북에서 한 번은 **PIN이 아닌 계정 비밀번호로 로컬 로그인**을 수행하거나, `설정 > 계정 > 로그인 옵션`에서 관련 보안 설정을 확인해 주세요.
